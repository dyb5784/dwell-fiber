# Claude Skills for Dwell-Fiber Development

This directory contains Claude skills specifically designed for Dwell-Fiber development workflows.

## Available Skills

### 1. `coq-lemma-fetch`
**Quick lemma lookup tool**

Retrieves lemma statements and proof sketches from `coq-signatures.md`.

**Usage in conversation:**
- "What does lemma `price_nonnegative` state?"
- "How was `bounded_loss_preserves_dwell_bound` proven?"
- "Show me the `wip_is_convex` lemma"

**What it does:**
- Searches `coq-signatures.md` for the requested lemma
- Returns statement + first few lines of proof
- ~200 tokens per lookup (96% reduction vs full proof)

**Files:**
- `.claude/skills/coq-lemma-fetch/SKILL.md`
- `coq-signatures.md` (generated by `make-coqindex.ps1`)

**Prerequisites:**
- Run `make-coqindex.ps1` first to generate `coq-signatures.md`

---

### 2. `coq-proof-tactics`
**Proof tactic suggestions**

Suggests appropriate Coq tactics based on proof goal types.

**Usage in conversation:**
- "I'm stuck proving an inequality in Coq"
- "What tactic should I use for `total_dwell` property?"
- "Suggest proof structure for event stream induction"

**What it covers:**
- Inequalities (R, nat, Z)
- List properties
- Event stream properties (Dwell-Fiber specific)
- Arithmetic expressions
- Propositional logic
- Universal/existential quantifiers

**Files:**
- `.claude/skills/coq-proof-tactics/SKILL.md`

**Key conventions:**
- Uses `bdestruct` for boolean reflection
- Suggests `lia` for linear integer arithmetic
- Recommends `lra` for real arithmetic
- Prefers structural induction for lists/streams

---

### 3. `coq-bugfix`
**Coq compilation error analysis**

Analyzes and fixes common Coq compilation errors.

**Usage in conversation:**
- "Coq error: Unknown tactic `bdestruct`"
- "Get type mismatch on `total_dwell` application"
- "Unresolved variables in price update lemma"
- "My proof compiles but verification fails"

**What it fixes:**
- Type mismatches
- Unknown tactics
- Unresolved variables
- Unfinished proofs
- Type class errors
- Ring/field operation errors
- Multiple goal abstraction issues

**Files:**
- `.claude/skills/coq-bugfix/SKILL.md`

**Auto-fix strategy:**
1. Classify error type
2. Suggest 2-3 specific fixes with code
3. Explain why error occurred
4. Provide prevention tips
5. Link to related lemmas

---

## Repository Context for Skills

### Coq Conventions (from `.claude/instructions.md`)
- Import namespace: `From Coq Require Import ssreflect ssrbool.`
- Boolean reflection: `destruct (x <=? y) eqn:H.`
- Custom tactics: `bdestruct`, `lia`, `bv_omega`
- When proof fails: first suggest `bdestruct` or `lia`
- Quote ≤5-line snippets to avoid context overflow

### Project Structure
```
coq/
├── dwell_stable.v              # ADMM stability proofs
├── dwell_kernel_resilience.v   # Event loss resilience
├── dwell_extended.v           # Liveness, fairness, attack resistance
└── test_resilience.v          # Test cases

.claude/
├── instructions.md            # Repository conventions
└── skills/
    ├── coq-lemma-fetch/      # Lemma lookup
    ├── coq-proof-tactics/    # Tactic suggestions
    └── coq-bugfix/          # Error fixing
```

### Verification Workflow

1. **Install Coq**: See `COQ_INSTALLATION.md`
2. **Verify installation**: `./verify-coq-installation.sh`
3. **Generate signatures**: `pwsh make-coqindex.ps1` (creates `coq-signatures.md`)
4. **Compile proofs**: `make coq`
5. **Verify proofs**: `make verify` or `./verify-proofs.sh`
6. **Enhanced verification**: `./scripts/coq-verify-enhanced.sh`

### Key Files for Skills

- **Coq proofs**: `coq/*.v`
- **Signatures**: `coq-signatures.md` (generated)
- **Installation**: `COQ_INSTALLATION.md`
- **Verification scripts**: `verify-*.sh`, `scripts/coq-verify-enhanced.sh`
- **Makefile**: `coq/` and root `Makefile`

## Example Conversations

### Example 1: Lemma Lookup

**User**: "What does `price_nonnegative` lemma state?"

**Claude uses `coq-lemma-fetch`**:
```bash
grep -i -A 8 "^### price_nonnegative$" coq-signatures.md | head -15
```

**Response**:
"The `price_nonnegative` lemma from `dwell_stable.v` states:

```coq
Theorem price_nonnegative :
  forall p d, 0 <= p -> 0 <= p + alpha * (d - budget).
Proof.
  intros p d Hp.
  lra.
Qed.
```

It proves the ADMM price update maintains non-negativity when the initial price is non-negative."

### Example 2: Proof Tactics

**User**: "I'm trying to prove a property about event loss patterns. What tactics should I use?"

**Claude uses `coq-proof-tactics`**

**Response**:
"For event stream properties in Dwell-Fiber, use structural induction:

```coq
unfold total_dwell.
induction stream.
- (* Empty stream *)
  simpl. lra.
- (* Event :: rest *)
  simpl. destruct pattern eqn:H.
  + (* Keep case *) apply IH.
  + (* Drop case *) lra.
```

Key tactics:
- `induction stream` - Structural induction on the stream
- `destruct pattern` - Handle loss pattern cases
- `lra` - Linear arithmetic for R calculations
"

### Example 3: Bug Fixing

**User**: "I'm getting 'Unknown tactic: bdestruct' error."

**Claude uses `coq-bugfix`**

**Response**:
"This means `bdestruct` isn't available. Three fixes:

**Fix 1** (recommended):
```coq
destruct (x <=? y) eqn:H.  (* Standard tactic, always available *)
```

**Fix 2**:
```coq
From Coq Require Import ssreflect ssrbool.  (* At top of file *)
bdestruct (x <=? y).
```

**Fix 3** (automatic):
```coq
destruct (x <=? y); try lia.  (* Destruct and try solving both cases *)
```
"

## Skill Development

To add new Coq skills:

1. Create new directory under `.claude/skills/`
2. Add `SKILL.md` with YAML frontmatter
3. Document purpose, usage, and examples
4. Reference relevant Coq files and conventions
5. Test skill with sample queries

## Maintenance

- **Keep skills updated** when Coq version changes
- **Regenerate signatures** when lemmas change: `pwsh make-coqindex.ps1`
- **Test scripts** regularly: `./scripts/coq-verify-enhanced.sh`
- **Monitor Coq build** in CI/CD

## Troubleshooting

**Skill not triggered?**
- Check `.claude/instructions.md` exists
- Ensure skill YAML format is correct
- Restart Claude Desktop/CLI

**Lemma lookup failing?**
- Run `make-coqindex.ps1` to regenerate `coq-signatures.md`
- Check file exists in project root
- Verify grep command syntax

**Tactics not working?**
- Verify Coq installation: `./verify-coq-installation.sh`
- Check imports match skill suggestions
- Use `--verbose` flag: `./scripts/coq-verify-enhanced.sh --verbose`
